# Desenho de oferta

Adaptado de `offers` (coreyhaines31/marketingskills, MIT) — cortadas as seções de high-ticket
B2B/curso/coaching (não se aplicam aos nichos que o VETOR atende: delivery, estética,
advocacia/arquitetura locais); mantido o núcleo — a Value Equation e os mecanismos de bônus/garantia
adaptados a promoção de negócio local.

## Quando usar

Cliente pede pra "montar uma promoção" e o pedido já veio com peça/copy em mente — antes de mandar
pro Design/Copy, cheque se a oferta *em si* está boa. Copy melhor numa oferta fraca converte pouco;
oferta melhor com copy mediano converte mais rápido.

## A Value Equation

```
Valor = (Resultado desejado × Chance percebida de conseguir) / (Tempo de espera × Esforço/sacrifício)
```

Pra melhorar uma oferta, mexa numa dessas quatro alavancas — não só no desconto:

- **Resultado desejado ↑**: nomeie o benefício real, não a mecânica ("sobremesa grátis" vende
  menos que "termine a semana sem cozinhar" quando aplicável).
- **Chance percebida ↑**: prova social real do cliente (nº de pedidos, avaliação), não invente
  número.
- **Tempo de espera ↓**: "pronto em 20min" > "peça já".
- **Esforço/sacrifício ↓**: reduza passo de decisão (pedido mínimo claro, sem letra miúda).

## Mecanismos (use com moderação — nunca todos ao mesmo tempo)

- **Empilhamento de valor**: 2 pizzas + refri nomeado como um combo, não como "desconto de 20%" —
  gente valoriza mais "ganhar algo" que "pagar menos".
- **Garantia/risco reverso**: só proponha se o negócio consegue honrar de verdade (nunca invente
  garantia que o cliente não pediu).
- **Urgência real**: prazo/quantidade que existe de fato (ex: "só nas terças", "enquanto durar o
  estoque") — nunca urgência falsa ("últimas horas" todo dia é mentira que queima confiança).

## Saída

`criar_briefing` com a oferta reformulada (nome, mecânica, condição, prazo) — pronto pra virar
input de uma etapa de Design/Copy separada. Esta skill nunca gera a peça final, só desenha o que a
peça vai comunicar.
