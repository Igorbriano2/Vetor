# Onboarding de marca pro Social Media

Adaptado da seção "Before Creating Content" de `social` (coreyhaines31/marketingskills, MIT) — o
original pergunta objetivo/público/tom/recursos antes de qualquer peça; aqui a diferença é que o
VETOR já tem `business_profiles`/`brand_kits` reais — esta skill lê primeiro, só pergunta o que
falta, e nunca reabre uma pergunta já respondida.

## Quando usar

Primeira interação de Social Media com um cliente novo, ou quando `ler_brand_kit`/`ler_perfil_negocio`
voltam vazios/incompletos pra uma peça que precisa dessa base.

## O que capturar (só o que faltar)

1. **Objetivo primário**: reconhecimento de marca, geração de pedido/lead, tráfego, comunidade —
   um negócio local geralmente quer pedido/reserva direto, não "engajamento" solto.
2. **Público**: quem de fato compra, em qual plataforma essa pessoa realmente está (não assuma
   todas — a maioria dos clientes do VETOR só precisa de 1-2 plataformas bem feitas, não 5 mal
   feitas).
3. **Tom de voz**: se já existe em `brand_kit.regras`, reforce; se não, pergunte 3 adjetivos que o
   dono usaria pra descrever como a marca fala.
4. **Recursos reais**: quantas peças por semana o negócio consegue sustentar de verdade (fotos
   novas, aprovação rápida) — nunca proponha uma cadência que o cliente não aguenta manter.

## Regra

Nunca "inventar" um tom de voz ou pilar de conteúdo sem essa base — se a informação não existe,
pergunte antes de propor a primeira peça (mesma regra do prompt do agente de Design pro brand kit).

## Saída

`criar_briefing` com o resumo — outras skills de Social Media (content-calendar, caption-writer)
leem esse briefing como ponto de partida.
