# apps/landing

Landing page pública do Vetor. Next.js + Tailwind, seguindo a estrutura de seções do
`docs/02-especificacao-landing-page.md` e a identidade visual de
`docs/01-identidade-de-marca-e-posicionamento.md`.

Captura leads (formulário + WhatsApp), exibe planos e prepara pixels de conversão (Meta/Google).

## Rodar localmente

```
cd apps/landing
npm install
npm run dev
```
