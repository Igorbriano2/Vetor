# apps/painel

Painel autenticado do cliente (Next.js + Tailwind + Supabase Auth). Mostra demandas, status de
entregas, aprovação de peças/campanhas e histórico — ver `docs/04-especificacao-tecnica-e-stack.md`
seção 3 para a modelagem de dados.

## Rodar localmente

```
cd apps/painel
npm install
npm run dev
```
